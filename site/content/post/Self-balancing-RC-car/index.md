## Project Overview

### 프로젝트 소개

본 프로젝트는 Atmega328p를 이용한 자동으로 균형을 잡는 RC 자동차입니다.

여태까지 배운 UART통신, I2C통신, PWM 이론을 바탕으로 스스로 균형을 잡는 자동차를 만들었습니다. 
PD 제어를 사용했으며, Atmega328p와 Atmel studio 7.0 툴을 이용했습니다.

### 프로젝트 정보

- **프로젝트명:** Atmega328p를 이용한 Self_Balancing_Rc_Car
- **개발 기간:** 2026.09.01 ~
- **진행 상태:** 진행중
- **주요 기술:** Atmega328p

### Development Purpose

여태까지 배운 임베디드 기초 이론을 이용해서 하나의 작품을 만들고 싶었습니다. 특히 관심이 많았던 **자동 균형 제어**를 한번 해보고 싶어서
**Self_Balancing_Rc_car** 프로젝트를 도전하게 되었습니다. 

### My Role

본 프로젝트는 개인 프로젝트로 진행하였으며, 제가 담당한 주요 개발 작업은 다음과 같습니다.

- 임베디드 시스템 구현: PWM, I2C, UART, GPIO 등 임베디드 시스템의 핵심 기술을 실제 하드웨어에 적용
- MCU 기반 제어 시스템 개발: ATmega328P를 활용하여 PD 제어 알고리즘을 구현하고, 차체의 균형 유지를 위한 모터 제어 시스템 개발
- 3D 모델링 및 기구 설계: Autodesk Fusion 360을 활용하여 자동차 프레임을 직접 설계하고 3D 모델링 수행

## Development

### System Architecture

본 시스템은 ATmega328P 마이크로컨트롤러를 기반으로 MPU6050 센서에서 자세 데이터를 수집하고, PID 제어 알고리즘을 통해 차체의 균형을 자동으로 유지하도록 설계한 2륜 RC 자동차입니다.

**1. Sensor Data Acquisition (MPU6050 & I2C)**

MPU6050 센서와 ATmega328P 간 I2C 통신을 통해 3축 가속도 및 각속도 데이터를 수집합니다. 수집된 데이터를 바탕으로 차체의 기울기를 추정하고, PID 제어 알고리즘의 입력값으로 활용합니다.

**2. PD Control Algorithm**

ATmega328P에서 목표 기울기와 현재 기울기 사이의 오차를 계산합니다. 비례(P), 미분(D) 제어 알고리즘을 활용하여 차체의 균형을 유지하는 데 필요한 모터 제어값을 계산합니다.

**3. Motor Control (PWM & GPIO)**

PD 제어 알고리즘에서 계산된 출력값을 바탕으로 PWM 신호를 생성하여 모터의 회전 속도를 조절합니다. GPIO를 통해 모터의 회전 방향을 제어하고, 차체의 기울기 변화에 대응하도록 구성합니다.

**4. UART Communication (Tera Term)**

ATmega328P와 PC 간 UART 시리얼 통신을 구성하고, Tera Term을 활용하여 센서 측정값 및 제어 데이터를 실시간으로 모니터링합니다. 이를 통해 센서 데이터의 변화와 PID 제어 동작을 확인하고, 시스템 디버깅 및 동작 분석에 활용합니다.

**5. Hardware Design & 3D Modeling**

Autodesk Fusion 360을 활용하여 자동차 프레임을 직접 설계하고 3D 모델링을 진행합니다. MCU, MPU6050 센서, 모터 등의 부품 배치와 차체의 무게중심을 고려하여 균형 제어에 적합한 하드웨어 구조를 설계합니다.

## Implementation Process

### 1. MPU6050 Sensor Data Processing

**MPU6050과 ATmega328P 간 I2C 통신**

자동차의 기울기를 측정하기 위해 MPU6050 관성 측정 센서를 활용하였습니다.
MPU6050은 3축 가속도계와 3축 자이로스코프를 내장하고 있으며, ATmega328P와 I2C 통신을 통해 센서 데이터를 수집하도록 구성하였습니다.
주요 개발 환경은 다음과 같습니다.

- **MCU:** ATmega328P
- **Sensor:** MPU6050
- **Communication:** I2C (TWI)
- **Development Tool:** Atmel Studio 7.0
- **Programming Language:** C

**센서 초기화 및 데이터 처리**

프로그램 시작 시 I2C_Init()과 MPU6050_Init() 함수를 호출하여 통신 및 센서를 초기화하고, Gyro_Calibration() 함수를 통해 자이로스코프 보정 과정을 수행하도록 구성하였습니다.

이후 메인 반복문에서 MPU6050_Read() 함수를 호출하여 센서 데이터를 읽고, Cal_Roll_Pitch() 함수를 통해 차체의 자세 정보를 계산하도록 구현하였습니다.

계산된 angles.pitch는 현재 차체의 기울기 정보로 사용하며, angles.GyroY는 회전 속도에 대한 제어 입력으로 활용하였습니다.
이를 통해 센서 데이터 수집부터 자세 추정, 제어 연산으로 이어지는 시스템을 구성하였습니다.

### 2. PD Control Algorithm

**PD 제어를 활용한 차체 균형 유지**

2륜 자동차의 균형을 유지하기 위해 비례(P) 및 미분(D) 제어 방식을 적용하였습니다.

현재 구현에서는 목표 기울기를 0도로 설정하고, 센서에서 계산된 Pitch 값과 목표 기울기 사이의 오차를 계산하도록 구성하였습니다.

**제어 오차 계산**
error = target_angle - angles.pitch

**제어 출력 계산**
output = Kp * error - Kd * angles.GyroY

주요 제어 계수는 다음과 같습니다.

- **Target Angle:** 0.0
- **Kp:** 37
- **Kd:** 0.5
- **Control Type:** PD Control

P 제어는 목표 기울기와 현재 기울기의 오차에 비례하여 모터 출력을 계산하며, D 제어는 자이로스코프에서 얻은 각속도 값을 활용하여 차체의 회전 움직임에 대응하도록 구성하였습니다.

**출력값 제한 및 안정성 고려**

PD 제어에서 계산된 출력값이 PWM 설정 범위를 초과하지 않도록 -1023부터 1023 사이로 제한하였습니다.

이를 통해 제어 연산의 출력값을 모터 구동에 사용할 수 있는 PWM 범위로 변환하도록 구현하였습니다.

현재는 PD 제어를 적용하고 있으며, 향후 적분(I) 제어를 추가하여 PID 제어 알고리즘으로 확장할 계획입니다.

### 3. Motor Control (Timer1 PWM & GPIO)

**ATmega328P Timer1을 활용한 PWM 제어**

모터의 회전 속도를 조절하기 위해 ATmega328P의 16비트 Timer1을 활용하였습니다.

PWM_init() 함수에서 Timer1을 Fast PWM 모드로 설정하였으며, ICR1 레지스터를 이용하여 PWM의 TOP 값을 1023으로 지정하였습니다.

주요 레지스터 설정은 다음과 같습니다.

- **TCCR1A / TCCR1B: Timer1의 PWM 동작 모드 설정**
- **ICR1: PWM TOP 값 설정 (1023)**
- **OCR1A: 첫 번째 모터의 PWM 출력값**
- **OCR1B: 두 번째 모터의 PWM 출력값**
- **PB1 (OC1A): 첫 번째 모터 Enable**
- **PB2 (OC1B): 두 번째 모터 Enable**

**GPIO를 활용한 모터 회전 방향 제어**

ATmega328P의 PORTC를 활용하여 모터 드라이버의 방향 제어 핀을 구성하였습니다.

- **PC0 / PC1:** 첫 번째 모터 방향 제어
- **PC2 / PC3: **두 번째 모터 방향 제어

Motor_Forward(), Motor_Backward(), Motor_Stop() 함수를 각각 구현하여 모터의 전진, 후진 및 정지 동작을 제어하도록 구성하였습니다.

PD 제어 알고리즘에서 계산된 출력값의 부호에 따라 모터의 회전 방향을 결정하도록 구현하였습니다.

- **output > 0:** 전진 방향으로 모터 구동
- **output < 0:** 후진 방향으로 모터 구동
- **output = 0:** 모터 정지

또한 출력값의 절댓값을 OCR1A, OCR1B에 적용하여 두 모터의 PWM 출력을 조절하도록 구성하였습니다.

**실시간 피드백 제어**

메인 반복문에서는 센서 데이터를 읽고, 자세를 계산한 후 PD 제어 출력을 모터에 적용하는 과정을 반복합니다.

각 반복의 마지막에는 _delay_ms(5)를 적용하여 다음 제어 연산 전 약 5ms의 대기 시간을 두도록 구성하였습니다.

이를 통해 센서 데이터와 모터 제어가 반복적으로 연결되는 피드백 제어 구조를 구현하였습니다.

### 4. UART Communication (Tera Term)

**ATmega328P와 PC 간 시리얼 통신**

임베디드 시스템의 동작 상태를 확인하고 디버깅하기 위해 UART 통신을 활용한 모니터링 기능을 구성하였습니다.

ATmega328P의 USART 기능과 PC의 Tera Term 프로그램을 활용하여 센서 데이터를 확인하는 방식을 적용하였습니다.

UART 통신 속도는 9600bps로 설정하는 코드를 작성하였으며, printf() 함수를 통해 데이터를 출력할 수 있도록 표준 출력 스트림을 UART에 연결하는 방식을 사용하였습니다.

**센서 데이터 모니터링**

센서에서 계산된 Roll, Pitch 데이터를 출력하는 디버깅 코드를 작성하여 차체의 기울기 변화를 확인할 수 있도록 구성하였습니다.

현재 메인 소스코드에서는 UART 초기화 및 데이터 출력 부분을 주석 처리한 상태이며, 필요에 따라 디버깅용으로 활성화할 수 있도록 작성하였습니다.

### 5. Hardware Design & 3D Modeling

**Autodesk Fusion 360을 활용한 프레임 설계**

자동차의 차체를 직접 설계하기 위해 Autodesk Fusion 360을 활용하여 3D 모델링을 진행하였습니다.

차체 설계 과정에서는 다음 요소들을 고려하였습니다.

- **ATmega328P 및 MPU6050의 장착 위치**
- **DC 모터와 바퀴의 결합 구조**
- **배터리 및 전자 부품의 배치 공간**
- **균형 제어를 위한 차체 무게중심**
- **부품 조립 및 유지보수 편의성**
- **하드웨어와 소프트웨어 통합**

직접 설계한 프레임과 MCU 제어 시스템을 결합하여 센서 데이터 수집, 제어 알고리즘, 모터 구동이 하나의 시스템으로 동작하도록 개발하고 있습니다.

이를 통해 기구 설계뿐만 아니라 MCU의 레지스터 설정, 센서 통신, PWM 제어 및 피드백 제어 알고리즘을 종합적으로 학습하고 있습니다.

## Project Results

### 1. 현재 구현 결과

**기울기 변화에 따른 모터 제어 구현**

현재 ATmega328P와 MPU6050을 활용한 센서 데이터 처리 및 PD 제어 기반 모터 구동 기능을 구현하였습니다.

차체의 기울기 변화에 따라 모터가 정상적으로 반응하는 것을 확인하였습니다.

- **전방 기울기 발생:** 차체가 앞으로 기울어지면 모터가 전진 방향으로 회전하여 균형을 회복하려는 동작 수행
- **후방 기울기 발생:** 차체가 뒤로 기울어지면 모터가 후진 방향으로 회전하여 균형을 회복하려는 동작 수행
- **PD 제어 적용:** MPU6050에서 측정한 기울기와 각속도를 기반으로 모터의 회전 방향 및 PWM 출력 제어

이를 통해 센서 데이터 수집, PD 제어 연산, 모터 구동으로 이어지는 피드백 제어 시스템이 정상적으로 동작하는 것을 확인하였습니다.

다만, 기울기에 따른 모터의 반응은 구현하였으나 **외부의 도움 없이 차체가 지속적으로 균형을 유지하는 단계에는 아직 도달하지 못하였습니다.**

### 2. 시스템 작동 영상

아래 영상은 현재까지 구현한 Self-Balancing RC Car의 실제 구동 모습을 보여줍니다.

MPU6050 IMU 센서를 통해 차체의 기울기와 각속도를 측정하고, PD 제어 알고리즘을 활용하여 기울어진 방향에 따라 모터의 회전 방향과 속도를 자동으로 조절하도록 구현하였습니다.

차체가 전방 또는 후방으로 기울어질 때 모터가 해당 방향으로 구동되며, 균형을 회복하기 위한 자세 교정 동작을 수행하는 것을 확인할 수 있습니다.

현재는 기울기 변화에 따른 모터 제어가 정상적으로 동작하는 단계이며, **지속적이고 안정적인 균형 유지를 위해 PD 제어 계수를 조정하고 있습니다.**

### 3. Problem Solving

**PD 제어 계수 최적화 문제**

현재 가장 큰 어려움은 차체가 안정적으로 균형을 유지할 수 있는 적절한 PD 제어 계수를 찾는 것입니다.

차체가 기울어지면 기울기 오차에 따라 모터가 반응하지만, 균형을 회복하는 과정에서 발생하는 반동과 지속적인 자세 변화를 안정적으로 제어하는 데 어려움이 있습니다.

현재 적용한 제어 계수는 다음과 같습니다.

- **Kp (비례 계수):** 37
- **Kd (미분 계수):** 0.5
- **Target Angle:** 0.0°

제어 계수에 따라 모터의 반응이 달라지므로, 차체의 움직임을 관찰하면서 적절한 값을 찾는 과정이 필요합니다.

특히 단순히 기울기에 빠르게 반응하는 것뿐만 아니라, 균형을 회복하는 과정에서 발생하는 진동과 반동을 줄이는 것이 중요하다고 판단하였습니다.

### 4. Future Improvements

**안정적인 균형 유지를 위한 개선 방향**

현재는 차체의 기울기에 따른 모터 제어가 구현된 상태이며, 지속적인 균형 유지를 목표로 제어 알고리즘을 개선하고 있습니다.

향후 개선할 사항은 다음과 같습니다.

- **PD 제어 계수 최적화:** Kp와 Kd 값을 조정하여 진동과 반동을 줄이고 안정적인 균형 유지 성능 확보
- **자세 추정 정확도 개선:** MPU6050의 센서 데이터를 분석하고 필터링 및 보정 방식 검토
- **제어 주기 안정화:** 일정한 제어 주기를 유지하도록 프로그램 개선
- **PID 제어 확장 검토:** 필요시 적분(I) 제어를 추가하여 제어 성능 비교

최종적으로 차체가 외부의 도움 없이 스스로 균형을 유지할 수 있는 안정적인 2륜 자동차를 완성하는 것을 목표로 하고 있습니다.

### 5. 느낀 점

처음 임베디드 개발을 접했을 때는 익숙하지 않은 분야에 대한 막연한 두려움과 어려움이 있었습니다. 관련 지식과 경험이 부족했기 때문에 어디서부터 시작해야 할지, 어떤 역량을 쌓아야 할지 많은 고민을 하였습니다.

그러던 중 ATmega328P 마이크로컨트롤러를 알게 되었고, 관련 강의와 자료를 찾아보며 하나씩 공부하기 시작했습니다. 처음에는 어렵게만 느껴졌던 임베디드 개발이었지만, 직접 코드를 작성하고 하드웨어를 제어하는 과정을 경험하면서 예상했던 것보다 훨씬 큰 흥미와 성취감을 느낄 수 있었습니다.

UART, SPI, I2C, GPIO, PWM 등 임베디드 시스템의 기초적인 개념을 학습하면서 **"지금까지 배운 기술들을 활용하여 나만의 작품을 만들어 보고 싶다."** 라는 생각을 하게 되었고, 이를 계기로 Self-Balancing RC Car 프로젝트를 시작하였습니다.

프로젝트를 진행하면서 UART 통신과 Tera Term을 활용한 센서 데이터 모니터링, I2C 통신을 이용한 MPU6050 센서 제어, GPIO와 PWM을 활용한 모터 구동 등 학습했던 이론을 실제 하드웨어에 적용할 수 있었습니다. 특히 센서에서 수집한 데이터를 바탕으로 제어 알고리즘을 구현하고, 그 결과가 실제 모터의 움직임으로 이어지는 과정을 경험하며 임베디드 시스템의 동작 원리를 더욱 깊이 이해할 수 있었습니다.

아직 안정적으로 균형을 유지할 수 있는 최적의 PD 제어 계수를 찾지는 못하였지만, 이번 프로젝트를 통해 **단순히 코드를 작성하는 것뿐만 아니라 문제의 원인을 분석하고, 반복적인 실험과 개선을 통해 해결해 나가는 과정이 중요하다는 것**을 배웠습니다.

앞으로도 부족한 부분을 꾸준히 학습하고, 시행착오를 두려워하지 않으며 목표한 기능을 완성할 때까지 도전하겠습니다. 이번 프로젝트를 시작으로 하드웨어와 소프트웨어를 함께 이해하고 개발할 수 있는 임베디드 개발자로 성장하고 싶습니다.
